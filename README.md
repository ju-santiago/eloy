# Eloy

**Sua empresa organizada. Sua rotina mais leve.**

## Sobre o projeto

Eloy é um sistema web de gestão para pequenos negócios, voltado principalmente para pequenas e microempreendedoras, com o objetivo de auxiliá-las na organização das demandas do dia a dia profissional.

## Funcionalidades

- Cadastro de vendas
- Cadastro de despesas
- Cadastro de produtos
- Cálculo automático do valor da venda
- Controle de quantidade de produtos
- Dashboard com vendas, pedidos, despesas e lucro estimado
- Armazenamento dos dados com LocalStorage
- Interface responsiva

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Status do projeto

Em andamento.

Versões posteriores poderão contar com:

- Cadastro de clientes
- Controle de pedidos frequentes de acordo com cada perfil cadastrado
- Controle financeiro semanal e mensal
- Auxílio na precificação de produtos e/ou serviços de acordo com os recursos e suas quantidades utilizadas
